# ESP32-C6 Wi-Fi Monitor

ESP32-C6-LCD-1.47 的独立 ESP-IDF 网页配网工程。

## 默认行为

- 无已保存配置或连接保存网络超过 30 秒：启动配网热点。
- 热点名称：`ESP32-C6-<SoftAP MAC>`。
- 默认热点密码：`12345678`。
- 配网页面：`http://192.168.4.1`。
- 运行期间短按 BOOT：按“默认仪表盘 → 接口1 → 接口2 → … → 默认仪表盘”循环切换。
- 默认仪表盘双击 BOOT：锁定当前轮播接口；再次双击解锁。锁定时接口名前显示红点。
- 运行期间长按 BOOT 3 秒：清除配置并重新进入配网模式。
- 目标 Wi-Fi 连接成功并获得 IP 后才保存配置，5 秒后关闭热点。

> 不要按住 BOOT 再上电。ESP32-C6 的 GPIO9 是启动配置引脚，这样可能进入下载模式而不会运行应用。

## 编译和烧录

请从 ESP-IDF Terminal 执行：

```powershell
cd "D:\Projects\Linux\OpenWRT Monitor\ESP32-C6-WiFi-Monitor"
idf.py build
idf.py -p COMx flash monitor
```

重命名前的旧编译缓存已清理，当前 `build` 目录保留。现有 `sdkconfig` 已指定 `esp32c6`，通常无需再运行 `set-target`。

将 `COMx` 替换为开发板实际串口。

可通过 `idf.py menuconfig` → `Wi-Fi provisioning` 修改热点名称前缀、热点密码、连接超时和长按时间。

## 使用方法

1. 首次启动设备。
2. 手机连接 `ESP32-C6-XXXXXXXXXXXX`，密码为 `12345678`。
3. 如果配置页未自动弹出，浏览器访问 `http://192.168.4.1`。
4. 点击“扫描附近 Wi-Fi”。
5. 选择目标网络并输入密码。
6. 点击“连接并保存”，等待成功提示。

ESP32-C6 仅扫描和连接 2.4 GHz Wi-Fi；纯 5 GHz SSID 不会出现。

> WPA2-PSK 密码最少为 8 个字符，因此不能把受保护热点密码设置为六位的 `123456`。这里使用最接近的 `12345678`；若必须显示为无需密码的热点，只能改为开放认证。

## 手机系统配置弹窗

固件通过 DHCP Option 114 公布配置页地址，并利用本地 DNS 和 HTTP 重定向
响应 Android、iOS 与 Windows 的联网探测。手机通常会显示“登录到网络”或
“此网络需要认证”，点击该系统通知即可进入配置页。

弹窗由手机操作系统控制，热点端无法保证每次强制显示。若未弹出，请暂时关闭
VPN、私人 DNS 和移动数据后忘记该网络并重新连接，或在浏览器手动打开
`http://192.168.4.1/`。必须使用 HTTP，不要使用 HTTPS。

## OpenWrt 状态显示

工程现已集成原开发板 ST7789/LVGL 显示支持，屏幕以 320×172 横向显示：CPU、
内存、温度、运行时间、WAN 实时上下行速度及累计上传下载量。速度自动使用
`B/s`、`KB/s`、`MB/s`，累计量自动使用 `B`、`KB`、`MB`、`GB`、`TB`。
速率和累计量统一按十进制换算（1 KB = 1000 B），显示小数四舍五入；波形页 Mbps 同样采用十进制。
CPU、MEM、TEMP、DOWNLOAD 和 UPLOAD 卡片使用带缓动过渡的液位背景，液面
绘制为连续起伏并横向流动的循环波浪；液位覆盖标题区域时标题切换为白色。
五张卡片采用错峰刷新，每轮只更新一张；在 60 Hz 显示循环下每张约有 12 次/秒
的更新机会，以避免同时刷新多个 Canvas 阻塞 SPI DMA。CPU、MEM 和 TEMP 分别按 100%、100% 和 100°C 满格，
DOWNLOAD 和 UPLOAD 的液位基础量程均为 10 MB/s；超过后各自按 10 MB/s
的倍数自动扩大量程并按比例显示（例如 15 MB/s 使用 20 MB/s 量程，液位为 75%）。
速度数字始终显示实际值。
默认仪表盘的 DOWNLOAD、UPLOAD、累计量和液位按接口轮播显示，每 10 秒切换
到下一个有效接口；右上角同步显示当前接口名称。双击 BOOT 可按接口名称锁定
当前接口，解锁后从当前接口重新开始 10 秒轮播计时。
后台持续记录每个网络接口的流量历史。短按 BOOT 可手动切换上下行波形监控页，
以绿色下载曲线和橙色上传曲线显示最近 120 秒数据，纵轴随峰值自动缩放。
达到 `10 MB/s` 时自动进入全屏波形页的功能暂时关闭；波形页仍可通过 BOOT
手动切换，流量下降也不会强制退出手动页面。
ESP32 最多为 16 个网络接口分别保存 120 点上下行环形缓冲；手动切换接口时，
波形、当前速度、平均速度、最大速度和纵轴缩放均使用该接口自己的数据。
波形页所有速度统一使用 Mbps，平均值和最大值按当前 120 点有效缓冲计算。
后台仍持续记录各接口历史，不受自动显示开关影响。
无操作 60 秒后背光降低到 25%；满 10 分钟后关闭 LCD 显示输出，背光 PWM 设为 0。
熄屏时第一次按下 BOOT 只唤醒，不切页、不切换接口锁定；恢复 50% 亮度并重新计时。
10 分钟熄屏独立于 OpenWrt 的屏保配置，时钟/GIF 屏保不会阻止熄屏；后台 Wi-Fi 和监控采集继续运行。

板载 GPIO8 RGB LED 每秒显示一次 ESP32-C6 本机处理器负载：绿色为 0–24%，
蓝色为 25–49%，黄色为 50–74%，红色为 75–100%。该指示灯不代表 OpenWrt
的 CPU 使用率。LVGL 使用双 40 行 DMA 绘图缓冲，以减少动画期间的 SPI 分块
刷新次数。
LVGL 界面以约 60 Hz 调用显示处理；监控数据仍为每秒采样一次。波形采用循环
扫描模式，从左向右按 `0s` 到负时间绘制。无论当前流量是否达到显示阈值，
120 点环形缓冲都会持续记录；手动切页时可立即显示此前的流量变化。
每次获得新采样后，最新点固定在左侧 `0s`，越旧的数据越靠右；仅进入页面或
切换接口时播放绘制动画，后续采样直接更新曲线。X 轴默认显示 10 秒，数据超过 10 秒后逐秒自动
扩展，最大显示到右侧 `-120s`；采样数据本身仍保持每秒一次。
Y 轴刻度显示在右侧。

配网页面需要同时填写 OpenWrt `esp32-status` Token，并可选填写“监控设备
IP”。填写 IP 时请求指定设备；留空时自动把 DHCP 默认网关作为 OpenWrt
地址，并请求：

```text
http://<指定IP或默认网关>/cgi-bin/esp32-status?token=<Token>
```

状态请求同时发送 `X-API-Token` 请求头与 URL Token，以兼容不转发自定义请求头的 uhttpd CGI；服务端需启用“允许 URL Token”（`allow_query_token=1`）。

### 服务端采样协议 v2

- 每秒串行请求一次，HTTP 超时为 5 秒；仍兼容未携带版本号的旧接口。
- 解析 `boot_id`、`collector_id`、64 位 `sample_seq`、`sample_end_ms`、`interval_ms` 和 `age_ms`；必要字段缺失或版本不支持时提示数据异常。
- 同一采样序号只记录一次，跳号保留实际时间空缺；路由器或采样进程重启时清空旧历史，同名接口的 `ifindex` 改变时重建该接口历史。
- `stale=true` 或数据年龄超过 3 秒时提示 `Data expired`，实时值显示不可用；本地持续计时，重复读取同一快照不会延长其有效期。请求耗时也计入数据年龄。
- CPU、内存、温度和速率的 `null` 显示为 `--`；真实零值仍显示为零。速率不可用时，有效累计字节数仍正常显示。
- 累计字节数按十进制整数直接解析到 `uint64_t`，避免 cJSON 的浮点数中转损失精度；显示继续采用十进制 KB/MB/GB/TB。
- 历史使用服务端采样时间的增量映射到本地时间轴，AVG 按各接口实际 `interval_ms` 加权；不对累计流量重新求差。旧接口继续使用本地请求窗口估算。
- 保留最近 120 秒、包含两端的 121 个秒级位置；按有效采样区间覆盖时间网格，避免非整数秒采样间隔造成假断点。真实缺失和无效数据仍留空，高速曲线按真实峰值动态缩放，最大值不受绘图坐标上限影响。

服务端插件及安装说明请使用对应的 OpenWrt 插件工程。

## 安全说明

- Wi-Fi 密码不会写入串口日志。
- 凭据仅在成功获得目标网络 IP 后写入 NVS。
- 量产时应通过 menuconfig 修改默认热点密码，最好为每台设备生成唯一密码。
